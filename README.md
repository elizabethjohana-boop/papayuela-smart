# Papayuela Smart

Sistema web para gestión agronómica de cultivos de papayuela, análisis de tratamientos, fertilización, producción, enfermedades y recomendaciones mediante un agente inteligente.

## Módulos
- Dashboard con explicación de tratamientos T1–T10
- Registro del cultivo
- Establecimiento y densidad de siembra
- Desarrollo, crecimiento y producción
- Fertilización
- Enfermedades
- Predicción orientativa
- Agente inteligente basado en datos históricos
- Resumen y exportación de datos locales

Sitio preparado para GitHub Pages.
